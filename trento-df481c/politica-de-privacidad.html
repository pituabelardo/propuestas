¿Qué datos tratamos y para qué?

Ninguno. Esta web no pide registro, no crea cuentas de usuario, no tiene formularios y no recoge ni un solo dato personal. No hay carrito ni pedido en línea: para pedir, la web te ofrece el teléfono del local para que llames tú.

Si llamas por teléfono, tus datos se tratan como en cualquier pedido de toda la vida: para preparar y entregar lo que has pedido.

Base legal

Como esta web no recoge datos, no hay tratamiento del que hablar. Si llamas al local para hacer un pedido, la base legal es la ejecución del contrato: sin tu nombre y tu teléfono no se puede preparar ni entregar el pedido.

Conservación

Esta web no almacena nada, ni en un servidor propio ni en tu navegador. Los datos de un pedido hecho por teléfono se conservan el tiempo necesario para servirlo y para cumplir las obligaciones fiscales y contables que exija la ley.

Tus derechos

Puedes ejercer tus derechos de acceso, rectificación, supresión, oposición, limitación y portabilidad escribiendo a hola@pizzeriademo.example. Si consideras que el tratamiento no se ajusta a la normativa, puedes reclamar ante la Agencia Española de Protección de Datos (www.aepd.es).
